ADR 004 - Escrita de testes
Data: 17-09-2026
Responsável: Timmy Chen

Contexto
Cada módulo do sistema e seus respectivos componentes precisam de 
verificações determinísticas para verificar a integridade e funcionamento de 
cada parte.

Decisão
Cada módulo deve ter sua pasta de testes cujo conteúdo pode possuir testes do 
tipo E2E, integração ou unitário, além de uma pasta de fixtures para preparar 
os ambientes de cada teste de maneira reutilizável.

Ao escrevê-los é essencial que sigam a estrutura AAA(arrange, act, assert), 
mantendo apenas uma verificação lógica.

Ademais, é fundamental que a cada feature adicionada, também seja projetado 
seus respectivos testes.

Justificativa
- Criar testes ao adicionar uma feature nova ajuda a garantir a qualidade e 
funcionamento do mesmo.
- Adotar apenas uma validação lógica por teste facilita saber exatamente o que 
quebrou no sistema.
