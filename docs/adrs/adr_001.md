ADR 001 - Framework Web
Data: 17-09-2026
Responsável: Timmy Chen

Contexto
O sistema precisa lidar com requisições HTTPS, para disponibilizar uma API 
que seja prioritariamente async devido ao core está fortemente ligado à 
geração de conteúdo por LLMs.

Decisão
O framework escolhido foi o FastAPI.

Justificativa
- Suporte nativo à rotas assíncronas.
- Forte comunidade.
- Validação de schemas na entrada.
