ADR 003 - DTOs
Data: 17-09-2026
Responsável: Timmy Chen

Contexto
As camadas de repository/cliente precisam conversar com use_cases que são 
utilizadas pelas rotas.

Decisão
As camadas devem se comunicar por DTOs.

Justificativa
- A utilização de DTOs desacopla a aplicação do formato de dado que uma fonte 
externa oferece.
