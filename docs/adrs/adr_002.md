ADR 002 - Escolha do banco de dados
Data: 17-09-2026
Responsável: Timmy Chen

Contexto
A aplicação precisa de um banco de dados, o qual será compartilhado entre 
todos os módulos. Sendo assim, o banco deverá ser robusto e possuir 
ferramentas para facilitar a implementação dos módulos.

Decisão
O banco de dados escolhido foi o Postgres.

Justificativa
- Plugin PGvector possibilita trabalhar com bases vetoriais em casos de RAG.
- Comunidade forte e excelente quantidade de materiais sobre.
- Suporta json como um tipo de dado, facilitando armazenar os meta dados de 
cada resposta de um workflow.
