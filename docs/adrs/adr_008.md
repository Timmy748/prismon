# ADR 008 - RBAC via mapa de permissões

Data: 17-09-2026  
Responsável: Timmy Chen

## Contexto

Para executar uma ação no projeto, é necessário verificar se o membro
possui a permissão correspondente.

## Decisão

As permissões serão agrupadas em um mapa em memória cuja chave é o cargo
e cujo valor é o conjunto de permissões desse cargo. A aplicação consultará
esse mapa para autorizar cada ação.

* `OWNER`: todas as permissões listadas abaixo.
* `DIRECTOR`: todas as permissões listadas abaixo.
* `MEMBER`: `chat:read`, `chat:create`, `chat:delete`, `chat:update`,
  `chat:send_message`, `document:create`, `document:read`,
  `document:delete`, `asset:create`, `asset:read`.
* `COLLABORATOR`: `workflow:use`.

As permissões administrativas são `member:invite`, `member:remove`,
`member:approve` e `member:change_role`. As permissões de documentos são
`document:create`, `document:read`, `document:delete`, `document:update`
e `document:approve`. As permissões de assets são `asset:create`,
`asset:read`, `asset:update` e `asset:approve`. As permissões de chat
são `chat:read`, `chat:create`, `chat:delete`, `chat:update` e
`chat:send_message`.

## Justificativa

Um mapa em memória permite verificar permissões sem consultar o banco
de dados para obter a lista de permissões do cargo. A busca do membro
continua necessária para confirmar sua associação ativa ao projeto.
