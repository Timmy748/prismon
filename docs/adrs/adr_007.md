# ADR 007 - Autorização baseada em RBAC por projeto

Data: 17-09-2026  
Responsável: Timmy Chen

## Contexto

Cada membro de um projeto deve poder executar ou não uma ação de acordo
com seu cargo naquele projeto.

## Decisão

O módulo de projetos terá quatro cargos: `OWNER`, `DIRECTOR`, `MEMBER` e
`COLLABORATOR`.

Os cargos `OWNER` e `DIRECTOR` podem acessar e modificar livremente os
documentos. O cargo `MEMBER` pode acessar documentos, mas precisa de
autorização para modificá-los. O cargo `COLLABORATOR` pode usar os
workflows do projeto.

## Justificativa

A separação de permissões por cargo reduz o risco de alterações
indevidas nos documentos do projeto.
